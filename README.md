# MAYBE LOVI Studio Website

Private project hub for the MAYBE LOVI candle / aroma / gift studio website.

This repository is used for:
- client requirements and confirmed decisions
- brand story and copywriting
- visual references and design system
- website scope and implementation planning
- SEO / GEO planning
- multi-agent collaboration
- progress logs and handoff notes

## Start here

Every agent must read these files before working:
1. `AGENTS.md`
2. `PROGRESS.md`
3. `docs/client-requirements.md`
4. `docs/decisions.md`
5. the relevant task file under `tasks/`

## Current status

The project is in **Discovery / Brand & Design Definition**.

Known direction:
- warm, caring, gift-oriented handmade brand
- soft pastel / macaron palette, simple Instagram-style visual language
- multilingual: Chinese / English / Malay
- product showcase + product detail pages
- social/contact links
- simple product-management backend
- SEO / GEO foundation
- first version may use concept/reference product imagery until real products are produced

See `PROGRESS.md` for the live status.

## Project structure

- `docs/` — requirements, scope, brand, decisions, open questions
- `references/` — website/product/visual references
- `content/` — website copy and SEO content
- `design/` — design system, page structure, asset checklist
- `tasks/` — roadmap and backlog
- `progress/` — dated work logs

## Rule

Do not silently turn assumptions into client requirements. If something is not confirmed, add it to `docs/pending-questions.md` and mark it as pending.
