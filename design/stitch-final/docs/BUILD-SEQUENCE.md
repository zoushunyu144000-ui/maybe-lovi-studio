# Recommended Build Sequence

1. Establish the shared design tokens, Header, Footer, and Menu Drawer.
2. Assemble Home.
3. Assemble Shop using the confirmed product model.
4. Assemble one reusable Product Detail template.
5. Add the scent-and-quantity bottom sheet as a state of Product Detail rather than a separate page.
6. Add cart state, local persistence, and subtotal behavior.
7. Add the confirmed external order handoff behavior from the repository requirements.
8. Add About, Studio, and Contact.
9. Adapt the public site for desktop using the retained desktop references while preserving the final mobile design system.
10. For admin, prioritize Login, Products, and Add/Edit Product before secondary dashboard/settings polish.

The public site does not need to wait for every admin screen before implementation begins.
