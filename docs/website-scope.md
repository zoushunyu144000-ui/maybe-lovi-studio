# Website Scope

## Current package baseline
Expected project package: RM899.

This file separates confirmed scope from future/optional scope so the project does not quietly expand.

## In scope now
- responsive branded website
- homepage / brand presentation
- product showcase
- product detail pages
- product image, price, and description fields
- featured / rotating product display on the main page
- contact information
- links to Facebook, Instagram, WhatsApp, Xiaohongshu
- location display/link when final details are supplied
- simple admin capability for product image, price, and description updates
- Chinese / English / Malay support
- SEO / GEO foundations
- integration of the existing client logo
- 5 initial product visuals as agreed

## Current product-image approach
The real product line does not exist yet.

Phase 1:
- establish brand and page framework
- use concept/reference-direction imagery only as temporary design material

Phase 2:
- replace temporary visuals with actual MAYBE LOVI product photography when products exist

## Not confirmed / not automatically included
The following must not be assumed:
- shopping cart
- online checkout
- payment gateway
- inventory management
- order-management dashboard
- customer accounts
- automated shipping calculations
- booking system
- advanced CRM
- unlimited product image generation
- unlimited revisions
- ongoing SEO ranking service
- ongoing content/translation maintenance

If any of these are requested later, treat them as a scope-change discussion.

## SEO / GEO expectation
The website can be technically prepared for discovery around relevant themes such as:
- aroma / fragrance
- gifts
- birthday gifts
- Christmas gifts
- handmade gifts

Do not promise specific Google rankings or automatic recommendation for broad keywords.

## Languages
Confirmed target languages:
- Chinese
- English
- Malay

Still to confirm:
- who provides final translation approval
- whether all product content must exist in all three languages from launch day

## Launch assumption
The site can be designed before the product line is complete, but launch readiness depends on whether the client wants a concept-stage public site or waits for real products.
