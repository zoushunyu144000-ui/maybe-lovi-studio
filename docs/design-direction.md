# Design Direction

Status: Initial direction only. Final visual system waits for more client reference websites.

## Desired feeling
- warm
- caring
- thoughtful
- handmade
- soft
- gift-oriented
- feminine but not childish
- simple and refined

## Existing client cues
- macaron / pastel colors
- simple Instagram-style feeling
- soft romantic brand references
- handmade candle / aroma / gift references
- existing MAYBE LOVI logo should guide the visual system
- new reference: `notebook therapy` / `Neko Cafe collection` presentation

## What the new reference suggests
The latest reference adds a clearer visual language:
- warm cream / beige / caramel / muted brown / soft yellow palette
- cute hand-drawn illustration details
- collection-led hero section with a strong visual scene
- coordinated desktop and mobile layouts
- playful but organized product presentation
- soft rounded cards / buttons rather than hard corporate UI
- small decorative motifs can support the brand, but should not make the site feel childish or crowded

## Recommended interpretation for MAYBE LOVI
- warm ivory / soft cream base
- muted pink, peach, caramel, beige and soft brown accents
- generous white space
- clean product presentation
- rounded but restrained interface elements
- elegant serif + clean sans-serif pairing, subject to reference review
- subtle handmade / illustrated details rather than heavy decoration
- keep the emotional warmth of the reference, but adapt it to fragrance, gifting and healing rather than copying the notebook/cat theme

## Trust / origin presentation
The website should eventually have a concise trust area for claims the client wants customers to notice, including:
- Korea-related product/fragrance origin information
- IFRA-related certification/compliance information

These should only be turned into badges or strong claims after the exact wording and evidence are confirmed.
