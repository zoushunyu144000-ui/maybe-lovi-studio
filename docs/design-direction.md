# Design Direction

Status: Initial direction only. Final visual system waits for more client reference websites.

## Desired feeling
- warm
- caring
- thoughtful
- handmade
- soft
- gift-oriented
- feminine but not childish
- simple and refined

## Existing client cues
- macaron / pastel colors
- simple Instagram-style feeling
- soft romantic brand references
- handmade candle / aroma / gift references
- existing MAYBE LOVI logo should guide the visual system

## Recommended interpretation
- warm ivory / soft cream base
- muted pastel accents
- generous white space
- clean product presentation
- rounded but restrained interface elements
- elegant serif + clean sans-serif pairing, subject to reference review
- subtle handmade details rather than heavy decoration

## Studio and founder imagery
When real photos become available, prioritize:
- studio details
- making process
- packaging
- materials
- product groupings
- natural workspace scenes
- a simple founder photo if May wants to appear

## Founder section
A small `Meet May` / `About the Maker` section can sit in the middle or lower part of the homepage.

## Product imagery before real products exist
Temporary concept visuals can be used for design exploration. They should be replaced with actual MAYBE LOVI product images once the real products are ready.

## Pending reference review
When the client sends additional websites, compare:
- colors
- typography
- spacing
- hero layout
- product-card style
- product-detail structure
- founder-story placement
- studio-photo usage
- CTA style

Then update this file with the final visual direction.
