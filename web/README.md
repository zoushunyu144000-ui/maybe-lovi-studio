# MAYBE LOVI Web App

Responsive React/Vite storefront assembled from the curated Stitch handoff.

## Run

```bash
npm install
npm run dev
```

## Current scope
- Home
- Shop
- Product detail gallery
- Scent + quantity bottom sheet
- Local cart persistence
- WhatsApp order handoff
- About / Studio / Contact
- Shared mobile menu, header and footer
